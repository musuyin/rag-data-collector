# 当前实现与下一步计划

打开 `index.html` 即可离线查看阶段展示稿。字体文件使用 CDN 声明；网络不可用时会使用系统字体，不影响布局和导航。

## 快捷键

- `←` / `→` / `Space`：翻页
- `F`：全屏
- `O`：总览
- `N`：当前页备注
- `S`：讲者视图
- `T`：切换 engineering-whiteprint、minimal-white、blueprint、tokyo-night 主题

展示稿基于 html-ppt 的 tech-sharing 模板和运行时资产改编。第三方代码采用 MIT License，详见 `LICENSE-html-ppt.txt`。

## 维护约定

1. **当前数字与结论**只改 `阶段总报告_当前_*.md`，不要改历史稿里的旧数字。  
2. 新开一周时：把上一份「当前」移入 `历史/`，再写新的 `阶段总报告_当前_YYYYMMDD.md`，并更新本 README 链接。  
3. 过程中的零散续报，合并进总报告后放入 `历史/`，避免根目录堆文件。

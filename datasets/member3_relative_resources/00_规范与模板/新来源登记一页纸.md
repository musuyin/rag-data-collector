# 新来源登记一页纸流程（人员三）

1. 分配下一个 `SRC-####`（查来源总表最大号 +1）
2. 填 `01_来源总表/来源总表.csv` 必填列：title, source_type, url_or_path, accessed_date, status, owner
3. 若落盘：按 `raw_archive/{类别}/SRC-####_短标题_YYYYMMDD.ext` 命名
4. 运行 `05_归档与哈希/compute_hashes.ps1`
5. 有实体/关系：更新 `02_关联关系表/`，再同步 `08_图谱关系导出/`
6. 有许可风险：更新 `07_缺口许可进度/许可问题表.csv`
7. 有冲突/重复：记入 `06_去重与冲突/`

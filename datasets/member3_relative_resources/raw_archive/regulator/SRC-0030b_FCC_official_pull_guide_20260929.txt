## How to pull official Grant (checklist)
1. Open https://www.fcc.gov/oet/ea/fccid
2. Enter Grantee Code + Product Code (e.g. SS3 + L2P2104)
3. Open Application → Exhibits → download Grant / Test Report if public
4. Save as: raw_archive/regulator/SRC-XXXX_{FCCID}_Grant_YYYYMMDD.pdf
5. Hash with compute_hashes.ps1

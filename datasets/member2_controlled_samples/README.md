# Member 2 Controlled Small Samples

This folder is the re-delivery requested for Member 4.

It contains one controlled small sample package per dataset:

- Anti-UAV300: one RGB/IR sequence with annotation and frame-pairing relation.
- DroneRF: one Parrot Bebop ON/Connected L/H CSV pair.
- MMAUD: one Camera + LiDAR + Radar timestamp sample from seq0001.

Each ZIP contains:
- README.md
- sample_manifest.json
- real sample data files

This is different from:
- `member2_multimodal_datasets.zip`: report-only validation deliverable.
- `member2_original_validation_data/`: large original validation packages.
